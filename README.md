# pasteit-support

Static support site for **PasteIt for macOS**, hosted with GitHub Pages. No build step, no JavaScript.

- **Support page:** https://liuyincarl.github.io/pasteit-support/ — used as the App Store *Support URL*
- **Privacy policy:** https://liuyincarl.github.io/pasteit-support/privacy.html — used as the App Store *Privacy Policy URL*

## Editing

Plain HTML/CSS:

- `index.html` — support page (features, FAQ, contact)
- `privacy.html` — privacy policy
- `styles.css` — shared styles (light/dark via `prefers-color-scheme`)
- `assets/icon.png` — app icon

Pushing to `main` redeploys the site automatically (usually within a minute).

## Support channel

Issues on this repository are the public support channel; keep this repo public so the
App Store links stay valid.
